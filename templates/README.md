# 아카이빙 입력 포맷

시트에서 채우고 통째로 올리는 방식입니다. 웹 폼에 한 명씩 넣지 않습니다.

## 파일 구성

| 파일 | 1행의 의미 | 관계 |
|---|---|---|
| `1_인플루언서.csv` | 사람 1명 | 마스터. `핸들`이 키 |
| `2_단가.csv` | 단가 항목 1개 | 1명이 여러 행 (피드/릴스 × 시점) |
| `3_캠페인.csv` | 캠페인 1개 | `캠페인코드`가 키 |
| `4_협업.csv` | 협업 1건 | 인플루언서 × 캠페인. `협업ID`가 키 |
| `5_콘텐츠성과.csv` | 측정 1회 | 게시물 1개가 여러 행 (24시간/7일/최종) |

구글 시트에 탭 5개로 만들고, 각 탭에 해당 CSV 헤더를 붙여 쓰면 됩니다.

## 절대 규칙 5개

이 5개만 지키면 임포트가 무조건 성공합니다.

1. **한 셀에 한 값.** `150/30` 금지. 피드 단가와 2차 활용비는 별도 컬럼입니다.
2. **셀 병합 금지.** 기존 시트의 병합셀이 이관을 가장 어렵게 만들었습니다. 값이 반복되면 반복해서 적습니다.
3. **핸들은 `@` 없이 소문자.** `@seucinnam` → `seucinnam`. 이게 사람을 식별하는 유일한 키입니다.
4. **금액은 만원 단위 숫자만.** `150만원`, `150,000` 금지 → `150`. 컬럼명에 단위가 박혀 있습니다.
5. **날짜는 `YYYY-MM-DD`.** `8/7`, `2026. 8. 7` 금지 → `2026-08-07`.

## 계산하지 마세요

CPV·참여율·뷰배수·티어·등급은 **사이트가 계산합니다.** 시트에 수식을 넣으면 행 추가·복붙에서 깨지고, 기준이 바뀌면 전부 다시 손봐야 합니다. 원본 숫자만 넣으세요.

## 여러 값을 한 칸에 넣을 때

`카테고리`, `태그`, `제공제품`만 세미콜론(`;`)으로 구분합니다.

```
카테고리:  패션;남성복
태그:      고퀄촬영;가성비
제공제품:  심볼 포인트 후드 집업 BN 0XL;핑거홀 롱슬리브 LM 0XL
```

## 최소한 이것만

500명을 다 채우려고 하면 시작을 못 합니다. **`1_인플루언서.csv`의 네 칸만** 채워도 명부는 돌아갑니다.

```
핸들, 플랫폼, 팔로워, 진행상태
```

나머지는 나중에 덧붙일 수 있습니다. 단가와 성과는 있는 것만 넣으세요.

## 이관 순서 권장

전부 옮기지 말고, 값어치 순으로 자릅니다.

| 순서 | 대상 | 왜 |
|---|---|---|
| 1 | **단가가 있는 사람** (약 117명) | 가장 자주 찾는 정보. 이것만 있어도 도구가 된다 |
| 2 | **게시물 링크가 있는 협업** (약 32건) | 성과 지표의 유일한 재료 |
| 3 | 현재 진행 중인 협업 | 지금 쓰는 데이터 |
| 4 | 과거 컨택 이력 (나머지) | 필요할 때 추가. 급하지 않다 |

4번은 안 해도 됩니다. 이름만 있고 단가도 성과도 없는 행은 옮겨도 검색에 안 걸립니다.

## 앞으로

과거 이관과 별개로, **신청 폼에 `업로드 링크` 항목을 추가**하는 게 가장 값싼 개선입니다. 그러면 앞으로의 협업은 백필이 아예 필요 없어집니다.
